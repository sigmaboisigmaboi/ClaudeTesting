# The Deep

A first-person, physics-based combat and exploration game set inside a vast underground civilization.

**Core identity: _Your choices become the enemy._** Break a bridge, sabotage a water pump, side with a faction — the world records it, and you meet the consequences later.

## Status

Pre-production. Design and decisions are locked; no gameplay code yet. Next: Phase 0 (Unity project setup), then prototype P1.
